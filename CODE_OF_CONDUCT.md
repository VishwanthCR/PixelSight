# Code of Conduct

## Our Standard

We aim to maintain a respectful, constructive and research-focused environment. Treat teammates with professionalism, discuss technical disagreements in good faith, and give credit for contributions.

## Collaboration

- Be respectful and inclusive.
- Focus criticism on ideas and implementation, not people.
- Document important research decisions.
- Ask for review when changes affect shared interfaces or experimental conclusions.

## Scope

This code of conduct applies to project discussions, issues, pull requests and other project collaboration spaces.
